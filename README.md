A tiny Node program that writes one single-line diagnosis from an AI therapist to `entry.txt` in the output directory, ready for the judge. In a calm clinical voice it diagnoses acute tab-hoarding disorder: you keep 87 tabs open not to read them, but because closing one feels like breaking up with a smarter version of you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
